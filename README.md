# Liferay Portal — Contributions Archive

Personal archive of my commit history from [liferay/liferay-portal](https://github.com/liferay/liferay-portal), covering my time as a Senior Software Engineer at Liferay (February 2019 – June 2026), most recently on the @liferay-content-management team. My employment at Liferay has since ended, and my work Liferay account is now disabled.

## Why this repository exists

GitHub does not count commits made in forks toward a user's contribution graph. To preserve a visible record of this work on my personal profile, I rewrote the authorship of my own commits from the upstream repository and pushed them here as an independent (non-fork) repository.

## Original activity

My pull requests, code reviews, and comments from this period can still be viewed on my [AliciaGarciaGarcia](https://github.com/AliciaGarciaGarcia) GitHub account, and in the upstream [liferay/liferay-portal](https://github.com/liferay/liferay-portal) repository. This repo is a copy for personal reference only — it is not a fork, is not actively maintained, and should not be used as a source for the Liferay Portal project.

## Areas of work

I worked on the [@liferay-content-management](https://github.com/orgs/liferay/teams/liferay-content-management) team, focused on Java backend development including Hibernate ORM, OSGi, DDM, Document Library architecture, Elasticsearch, headless REST APIs, feature flags, and Poshi/Playwright testing.
